🔴 ЭКСПЕРИМЕНТ 1 · МИГАЮЩИЙ СВЕТОДИОД (HELLO, WORLD!)

⚡ digitalWrite() · delay() · Первая схема

🔧 СХЕМА 1: Светодиод + резистор 220 Ом

🟢 Анод (длинная ножка) → пин 13 (через резистор)
⚫ Катод (короткая ножка) → GND

💾 Сохраните как: 01_blink в Tinkercad

// ЭКСПЕРИМЕНТ 1: Мигаем светодиодом // Это как "Hello, World!" в программировании void setup() { pinMode(13, OUTPUT); // Пин 13 будет работать как выход } // (мы будем подавать напряжение) void loop() { digitalWrite(13, HIGH); // Включаем светодиод (5 вольт) delay(1000); // Ждём 1 секунду (1000 мс) digitalWrite(13, LOW); // Выключаем светодиод (0 вольт) delay(1000); // Ждём ещё секунду // И всё повторяется снова! }
🔬 ФАКТ О КОДЕ: pinMode(13, OUTPUT); — говорим Ардуино: "Пин 13, ты теперь будешь лампочкой, давай свети!". digitalWrite даёт команду "ВКЛ" (HIGH) или "ВЫКЛ" (LOW). А delay(1000); — это "подожди 1000 миллисекунд", то есть 1 секунду. Всё просто!
🎯 ПОЧЕМУ РЕЗИСТОР? Если подключить светодиод напрямую к 5V, он сгорит за секунду (слишком большой ток). Резистор 220 Ом ограничивает ток — светодиод светит ярко, но не умирает. В Tinkercad можно и забыть резистор — симуляция покажет ошибку, но ничего не сгорит 😊

🎛️ ЭКСПЕРИМЕНТ 2 · РЕГУЛИРУЕМ ЯРКОСТЬ (ПОТЕНЦИОМЕТР)

⚡ analogRead() · map() · analogWrite()

🔧 СХЕМА 2: Потенциометр + светодиод

🎛️ Потенциометр: левый контакт → 5V, правый → GND, средний → A0
💡 Светодиод через резистор 220 Ом → пин 9 (PWM!)

💾 Сохраните как: 02_potentiometer

// ЭКСПЕРИМЕНТ 2: Крутим ручку — меняем яркость void setup() { pinMode(9, OUTPUT); // Пин 9 умеет менять яркость (PWM) Serial.begin(9600); // Включаем связь с компьютером } void loop() { int potValue = analogRead(A0); // Читаем напряжение с потенциометра (0..1023) // Преобразуем 0..1023 в 0..255 (диапазон яркости) int brightness = map(potValue, 0, 1023, 0, 255); analogWrite(9, brightness); // Устанавливаем яркость // Для любопытных: выводим значения в монитор порта Serial.print("Потенциометр: "); Serial.print(potValue); Serial.print(" → Яркость: "); Serial.println(brightness); delay(50); // Небольшая пауза для стабильности }
📊 МАГИЯ MAP: map() — это пропорция из школьной математики. Если potValue = 512 (половина от 1023), то map выдаст 128 (половина от 255). Формула: значение = (potValue * 255) / 1023. Просто и гениально!
💡 PWM — ЧТО ЭТО? Пины с ~ (3,5,6,9,10,11) умеют не просто включать/выключать, а быстро мигать. Так быстро, что глаз видит это как изменение яркости. 0 = всегда выключен, 255 = всегда включен, 127 = полсекунды светит, полсекунды нет.

🔘 ЭКСПЕРИМЕНТ 3 · КНОПКА-ВЫКЛЮЧАТЕЛЬ

⚡ digitalRead() · Подтягивающий резистор

🔧 СХЕМА 3: Кнопка + светодиод

🔘 Кнопка: один контакт → 5V, другой → пин 2 и резистор 10кОм → GND
💡 Светодиод через резистор 220 Ом → пин 13

💾 Сохраните как: 03_button

// ЭКСПЕРИМЕНТ 3: Кнопка управляет светодиодом // Нажал — горит, отпустил — погас #define BUTTON_PIN 2 #define LED_PIN 13 void setup() { pinMode(LED_PIN, OUTPUT); pinMode(BUTTON_PIN, INPUT); // Кнопка — это вход Serial.begin(9600); } void loop() { int buttonState = digitalRead(BUTTON_PIN); // Читаем кнопку if (buttonState == HIGH) { // Если нажата (напряжение есть) digitalWrite(LED_PIN, HIGH); Serial.println("Кнопка нажата!"); } else { digitalWrite(LED_PIN, LOW); } delay(50); }
🔌 ПОДТЯГИВАЮЩИЙ РЕЗИСТОР: Когда кнопка не нажата, пин 2 "висит в воздухе" — непонятно, что там (наводки, помехи). Резистор 10 кОм подтягивает его к GND, поэтому в покое читаем LOW. При нажатии — 5V побеждает, читаем HIGH. В Tinkercad можно использовать внутренний резистор: pinMode(BUTTON_PIN, INPUT_PULLUP); — тогда код будет наоборот (нажатие = LOW).

📏 ЭКСПЕРИМЕНТ 4 · УЛЬТРАЗВУКОВОЙ ДАЛЬНОМЕР (ПАРКТРОНИК)

⚡ pulseIn() · HC-SR04 · Сантиметры

🔧 СХЕМА 4: Ультразвуковой датчик + зуммер

📏 HC-SR04: VCC→5V, GND→GND, Trig→D9, Echo→D10
🔊 Зуммер: +→D8, -→GND

💾 Сохраните как: 04_ultrasonic

// ЭКСПЕРИМЕНТ 4: Парктроник — пищит, когда близко #define TRIG 9 #define ECHO 10 #define BUZZER 8 void setup() { pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); pinMode(BUZZER, OUTPUT); Serial.begin(9600); Serial.println("Ультразвуковой парктроник запущен!"); } void loop() { // Посылаем ультразвуковой импульс digitalWrite(TRIG, LOW); delayMicroseconds(2); digitalWrite(TRIG, HIGH); delayMicroseconds(10); digitalWrite(TRIG, LOW); // Измеряем время возвращения эха long duration = pulseIn(ECHO, HIGH); // Вычисляем расстояние (скорость звука 343 м/с) int distance = duration * 0.034 / 2; // /2 потому что туда и обратно // Ограничиваем до 200 см (дальше не интересно) if (distance > 200) distance = 200; Serial.print("Расстояние: "); Serial.print(distance); Serial.println(" см"); // Чем ближе объект, тем чаще пищим if (distance < 50) { int beepDelay = map(distance, 0, 50, 50, 500); tone(BUZZER, 2000, 50); delay(beepDelay); } else { noTone(BUZZER); delay(100); } }
🦇 КАК ЭТО РАБОТАЕТ? Датчик посылает ультразвук (как летучая мышь!) и засекает время возвращения эха. Звук летит со скоростью 343 м/с, или 0.034 см/мкс. Формула: расстояние = время * скорость / 2. Время в микросекундах, делим на 2, потому что звук летит туда и обратно.
🚗 ГДЕ ИСПОЛЬЗУЕТСЯ? В автомобильных парктрониках, роботах-пылесосах (чтобы не врезаться), в автоматических дверях. В Tinkercad можно подвигать объект мышкой — расстояние изменится!

🌈 ЭКСПЕРИМЕНТ 5 · RGB-СВЕТОДИОД (МИЛЛИОНЫ ЦВЕТОВ)

⚡ Три канала · Смешение цветов

🔧 СХЕМА 5: RGB-светодиод + 3 резистора

🔴 Красный → D9 через 220Ω
🟢 Зелёный → D10 через 220Ω
🔵 Синий → D11 через 220Ω
⚫ Общий катод → GND

💾 Сохраните как: 05_rgb

// ЭКСПЕРИМЕНТ 5: RGB-светодиод — магия цвета // Плавно переливается всеми цветами радуги #define RED 9 #define GREEN 10 #define BLUE 11 void setup() { // Ничего не настраиваем — analogWrite не требует pinMode } void loop() { // Красный -> Жёлтый (увеличиваем зелёный) for (int i = 0; i <= 255; i++) { analogWrite(RED, 255); analogWrite(GREEN, i); analogWrite(BLUE, 0); delay(5); } // Жёлтый -> Зелёный (уменьшаем красный) for (int i = 255; i >= 0; i--) { analogWrite(RED, i); analogWrite(GREEN, 255); analogWrite(BLUE, 0); delay(5); } // Зелёный -> Бирюзовый (увеличиваем синий) for (int i = 0; i <= 255; i++) { analogWrite(RED, 0); analogWrite(GREEN, 255); analogWrite(BLUE, i); delay(5); } // И так далее... полный цикл радуги }
🎨 КАК ПОЛУЧАЮТСЯ ЦВЕТА? Телевизор, монитор и этот светодиод работают одинаково: смешивают красный, зелёный и синий. Красный + зелёный = жёлтый. Зелёный + синий = бирюзовый. Красный + синий = пурпурный. Все три вместе = белый. Меняя яркость каждого канала, можно получить 256×256×256 = 16 миллионов цветов!

🌡️ ЭКСПЕРИМЕНТ 6 · ЭЛЕКТРОННЫЙ ТЕРМОМЕТР

⚡ TMP36 · Температура в °C · LCD-дисплей

🔧 СХЕМА 6: TMP36 + LCD 16x2 (I2C)

🌡️ TMP36: левый → 5V, правый → GND, средний → A0
📟 LCD I2C: VCC→5V, GND→GND, SDA→A4, SCL→A5

💾 Сохраните как: 06_thermometer

// ЭКСПЕРИМЕНТ 6: Цифровой термометр на LCD // В Tinkercad используется библиотека LiquidCrystal_I2C #include <LiquidCrystal_I2C.h> LiquidCrystal_I2C lcd_1(0x27, 16, 2); // Адрес 0x27, 16 колонок, 2 строки #define TEMP_PIN A0 void setup() { lcd_1.init(); // Запускаем дисплей lcd_1.backlight(); // Включаем подсветку lcd_1.setCursor(0, 0); lcd_1.print("Termometer"); delay(2000); lcd_1.clear(); } void loop() { int sensorValue = analogRead(TEMP_PIN); // TMP36: 10 мВ на °C, 0°C = 500 мВ float voltage = sensorValue * (5.0 / 1023.0); float temperature = (voltage - 0.5) * 100; lcd_1.setCursor(0, 0); lcd_1.print("Temp: "); lcd_1.print(temperature, 1); lcd_1.print(" C "); // Пробелы для очистки lcd_1.setCursor(0, 1); if (temperature < 18) { lcd_1.print("❄️ Cold! "); } else if (temperature > 26) { lcd_1.print("🔥 Hot! "); } else { lcd_1.print("✅ Comfort "); } delay(500); }
🌡️ ФОРМУЛА ТЕМПЕРАТУРЫ: TMP36 выдаёт 0.5В при 0°C и добавляет по 10 мВ на каждый градус. То есть при 20°C напряжение = 0.5 + 0.01*20 = 0.7В. Формула: T = (напряжение - 0.5) * 100. Гениально просто!
📟 ПРО LCD В TINKERCAD: В Tinkercad используется библиотека LiquidCrystal_I2C, а не Adafruit_LiquidCrystal. Адрес по умолчанию — 0x27. Не забудьте вызвать lcd_1.init(); и lcd_1.backlight();!

🔄 ЭКСПЕРИМЕНТ 7 · УМНЫЙ СВЕТОФОР (ИТОГОВЫЙ ПРОЕКТ)

⚡ Собираем всё вместе: кнопка + светодиоды + дальномер

🔧 СХЕМА 7: Светофор с кнопкой для пешеходов

🚦 Красный → D13, Жёлтый → D12, Зелёный → D11 (все через резисторы 220 Ом)
🔘 Кнопка на D2 (с резистором 10 кОм к GND и проводом к 5V)

💾 Сохраните как: 07_traffic_light

// ЭКСПЕРИМЕНТ 7: Пешеходный светофор // Обычный режим: зелёный для машин // Нажали кнопку → красный для машин, потом зелёный для людей #define RED 13 #define YELLOW 12 #define GREEN 11 #define BUTTON 2 void setup() { pinMode(RED, OUTPUT); pinMode(YELLOW, OUTPUT); pinMode(GREEN, OUTPUT); pinMode(BUTTON, INPUT); Serial.begin(9600); // Начинаем с зелёного для машин digitalWrite(GREEN, HIGH); digitalWrite(YELLOW, LOW); digitalWrite(RED, LOW); } void loop() { // Проверяем кнопку (HIGH = нажата, потому что у нас резистор к GND) if (digitalRead(BUTTON) == HIGH) { Serial.println("Кнопка нажата! Переключаем для пешеходов."); // Выключаем зелёный, включаем жёлтый digitalWrite(GREEN, LOW); digitalWrite(YELLOW, HIGH); delay(2000); // Жёлтый горит 2 секунды // Выключаем жёлтый, включаем красный digitalWrite(YELLOW, LOW); digitalWrite(RED, HIGH); delay(5000); // Красный горит 5 секунд (пешеходы идут) // Возвращаем зелёный digitalWrite(RED, LOW); digitalWrite(GREEN, HIGH); // Небольшая задержка, чтобы кнопка не сработала снова сразу delay(500); } // Обычный цикл не нужен — светофор просто горит зелёным, // пока не нажмут кнопку }
🚦 НАСТОЯЩИЙ СВЕТОФОР: В реальных светофорах всё сложнее: датчики машин, пешеходные кнопки с подсветкой, синхронизация перекрёстков. Но принцип тот же: состояния (зелёный/жёлтый/красный) и таймеры. В Tinkercad можно добавить второй светофор и синхронизировать их!
🎯 ИТОГ: В этом проекте вы использовали digitalWrite для светодиодов, digitalRead для кнопки, delay для таймингов. Это основа любой системы управления!

🧠 5 ФАКТОВ, КОТОРЫЕ НУЖНО ЗНАТЬ

1️⃣ digitalWrite — это просто выключатель. Либо есть напряжение (HIGH), либо нет (LOW).
2️⃣ analogRead возвращает число от 0 до 1023. 0 = 0V, 1023 = 5V. Потому что АЦП 10-битный (2¹⁰ = 1024).
3️⃣ analogWrite работает только на пинах с ~ (3,5,6,9,10,11). Это ШИМ — быстрое мигание, глаз видит как яркость.
4️⃣ delay() останавливает программу. Пока идёт задержка, Ардуино ничего не делает. Для нескольких задач одновременно используют millis().
5️⃣ В Tinkercad можно нажимать кнопки, крутить потенциометры и даже двигать объекты перед ультразвуковым датчиком — и всё работает!

🎁 БОНУС: НОЧНИК С ФОТОРЕЗИСТОРОМ

🔧 БОНУСНАЯ СХЕМА: Фоторезистор + светодиод

📦 Фоторезистор: один контакт → 5V, другой → A1 + резистор 10кΩ → GND
💡 Светодиод через резистор 220 Ом → D9

Чем темнее, тем ярче светит светодиод — автоматический ночник!

// БОНУС: Автоматический ночник // Чем меньше света, тем ярче светодиод #define LDR_PIN A1 #define LED_PIN 9 void setup() { pinMode(LED_PIN, OUTPUT); Serial.begin(9600); } void loop() { int lightLevel = analogRead(LDR_PIN); // 0 (темно) .. 1023 (светло) // Инвертируем: чем темнее, тем больше яркость int brightness = map(lightLevel, 0, 1023, 255, 0); analogWrite(LED_PIN, brightness); Serial.print("Свет: "); Serial.print(lightLevel); Serial.print(" → Яркость: "); Serial.println(brightness); delay(100); }
📦 ФОТОРЕЗИСТОР: Его сопротивление меняется в зависимости от освещения. Чем светлее, тем меньше сопротивление. Вместе с постоянным резистором 10 кОм они образуют делитель напряжения. Чем темнее, тем выше напряжение на A1.
